# 在私人 Mac 查看当前 Demo

## 最短路径：不用安装开发环境

1. 用 symbi 登录 GitHub，打开私人仓库 symbi/ai-payment-demo。
2. 选择 Code → Download ZIP，解压。
3. 在 Finder 中找到 docs/offline-pay.html，双击用浏览器打开。
4. 选择场景，点击 Pay，查看权重、贡献分、总风险分与决定。

如果双击打开编辑器，请右键 → 打开方式 → Safari 或 Chrome。
GitHub 文件预览不会执行 HTML；需要下载到本机打开。

## 验收重点

- 正常场景：默认权重下 0 分，允许模拟购买，显示本地报告素材。
- 风险提示：默认 30 分，暂缓。
- 明确风险、预算不足、付款内容改变：硬拒绝，不能通过调低权重绕过。
- 历史数据不足：总分未知，不冒充 0 分。
- 修改权重或场景后，旧决定清空，重新点击 Pay。
- 权重必须合计 100%；所有数据为合成示例，不读取真实钱包。

这版不需要 npm ci、npm run dev，也不需要私钥或 API key。
没有真实签名、交易或结算；浏览器视觉验收仍需实际查看。

## 之后如果要让另一台电脑访问

先确认公司政策允许两台设备互访，且两台电脑确实在可互通的网络上。
物理隔离的网络不能仅靠启动网页服务器打通。
当前只交付静态文件，不自动启动服务器，不监听局域网或公网，
不创建隧道、不开放远程终端，也不代理访问外部付款服务。
后续若获准，只托管这一个静态演示文件；不暴露整个仓库、.env 或后端。

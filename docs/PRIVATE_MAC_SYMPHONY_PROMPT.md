FIELD_MAP 至少包含：实际 endpoint/版本、字段路径、类型、量纲、稳定标签及含义、风险对象与覆盖、完整性、时间来源、确认依据、mappingVersion。用对应端点官方文档/类型或供应商明确答复确认语义；几次返回观察不能证明范围或阈值。只有网页截图或猜测时写未知。

## 如需新增真实扫描

先记录这批获准的候选、请求数上限和费用边界；缺预算信息时完成现有材料整理并向本机操作者确认，不默认无限额度或新增收费。一个用户动作最多一次扫描，自动重试为零；失败/限流记录结果后停止该样本，不重复刷新触发调用。

仅复用 `docs/PRIVATE_MAC_RISK_CHECK.md` 的 scan-only 入口，保持付款关闭。当前 scanner 即使收到合法数据仍返回 HOLD，这是当前代码行为，不代表样本天然危险。

证据里区分供应商事实、我们的策略决定、最终 guard 和执行状态。记录实际原始分数而不默认 `/100`；未知量纲/必要标签/覆盖保持未知。检查 requestedNetwork 只是调用方记录还是供应商真正回显，receivedAt 不冒充 providerUpdatedAt。

只保留有界数值及允许的标签/类型结构。不要把 API key、请求头、.env、完整自由文本、可执行签名或未获授权的个人信息放入产物。结构不兼容时返回字段路径/类型的脱敏差异；不要为了通过解析直接放宽验证或把未知填成安全。
